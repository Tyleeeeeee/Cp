\noindent \textbf{Solution}\\
The idea is for any given two position $x$ and $y$,you can query ? $x$ $y$ and ? $y$ $x$,let the response be $l$ and $r$,the you can observe that if $l>r$ then $a_x=l$ otherwise $a_y=r$ and every $2$ query will determine $1$ element,thus at most $2\cdot (n-1)$ query is enough
